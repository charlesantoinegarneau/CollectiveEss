# Brainstorming

## Description

Socratic design refinement - A collaborative approach to exploring and refining ideas through guided questioning and dialogue.

## Purpose

Help transform initial ideas into well-formed designs through the Socratic method of questioning, allowing for deep exploration of requirements, constraints, and possibilities before implementation.

## Key Features

- One question at a time approach
- Multiple choice questions when possible
- Iterative refinement through dialogue
- Design presentation in digestible sections
- Validation at each step

# Subagent-Driven Development

## Description

Fast iteration with two-stage review - Accelerate development by using subagents for implementation with systematic spec compliance and code quality reviews.

## Purpose

Enable rapid development cycles by delegating implementation to subagents while maintaining quality through a structured two-stage review process.

## Key Features

- Subagent-based implementation
- Stage 1: Spec compliance review
- Stage 2: Code quality review
- Fast iteration cycles
- Clear separation of concerns between implementation and review

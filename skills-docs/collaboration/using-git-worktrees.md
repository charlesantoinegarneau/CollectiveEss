# Using Git Worktrees

## Description

Parallel development branches - Use git worktrees to work on multiple branches simultaneously in isolated directories.

## Purpose

Enable parallel development workflows by maintaining multiple working directories for different branches without constant switching.

## Key Features

- Multiple concurrent working directories
- Branch isolation
- Shared git history and objects
- Easy context switching
- Parallel feature development
